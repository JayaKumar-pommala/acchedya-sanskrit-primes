# acchedya-sanskrit-primes
Primality testing built only from procedures stated in Sanskrit mathematical texts (Gaṇita Kaumudī, Āryabhaṭīya, Līlāvatī, Śatapatha Brāhmaṇa), with no %, / or √ rule. Includes the source verses (checked by metre and arithmetic), a separate modern layer for cross-checking, and full tests
