# Sanskrit Source-Led Arithmetic and Acchedya Testing

This repository documents a source-led arithmetic experiment built from Sanskrit procedures associated with division, mutual remainders, square-root extraction, divisibility checks, and difference-of-squares factoring.

## Status and scope

This is a **modern implementation and textual research dossier**. It is not a prime-generating formula, and no cited passage gives a formula for the next prime. The textual contribution is the mapping of particular procedures to particular passages, together with a record of the readings and uncertainties.

The default `blocks.decide(n)` routine is an exact decision algorithm when allowed to finish, but its stopping rule uses a **derived mathematical bound** that is not stated in the Sanskrit. It combines two source-inspired searches:

1. Try acchedya divisors, beginning with those named in the provisional Gaṇita Kaumudī reading.
2. Search for a square difference, using (n+s^2=b^2), which yields factors (b-s) and (b+s).
3. Stop when the searches meet under the documented derived bound.

The literal routes (`vibhaga`, `gk-trial`, and `vargantara`) do not use that meeting bound and can be dramatically slower. Setting `use_root_stop=True` uses the modern square-root stopping theorem and is off by default.

The code avoids Python's `%`, `//`, `/`, and `**` operators in `blocks.py`; it constructs division and square-root extraction from decimal digits, multiplication, and comparison. It still uses modern programming-language features such as strings, lists, loops, and control flow. This is an implementation constraint, not evidence that the historical authors used the same machine procedure.

## What the checks establish

`check_verses.py` checks that selected spans occur in the supplied corpus, parses number words, recomputes arithmetic, and diagnoses metre. A passing row means only that the coded assertion passed against the data supplied to it. It does **not** authenticate the source, prove a transcription, or independently collate a scan. Informational rows are marked separately.

`test_blocks.py` is designed to compare arithmetic routines with ordinary arithmetic and to compare primality outcomes with a trial-division oracle over finite ranges and selected random samples. These tests provide finite evidence, not an all-integers proof. The algorithm's proof obligation for the derived meeting bound is stated separately in the dossier.

No modern timing comparison is asserted here. The `prime_model.py` dependency needed by `engines.py` is not part of this archive, so the optional modern cross-check and benchmark are not reproducible from this bundle alone.

## Reproduce the local reports

Requires Python 3.10 or later. The source-led routines use only the Python standard library.

```bash
python check_verses.py
python make_doc.py
python test_blocks.py
```

`test_blocks.py` does not need the modern engine for its source-led checks. Its optional modern-layer comparison is skipped unless the separate `prime_model.py` dependency is available. Do not interpret the test script's finite ranges as proof for all integers.

## Research and publication checklist

1. Collate the Gaṇita Kaumudī chapter 11 OCR readings against Dvivedī's 1942 scan; record page numbers and variants. Do not quote the present GK readings as a verified complete text.
2. Keep source wording, translation, modern implementation, and derived proof visibly separate.
3. Retain the distinction in ŚB 10.4.2 between *naiva vyāpnot* for unsuccessful ritual attempts whose arithmetic division works and *na …-dhā vyabhavat* for divisions that fail.
4. Verify every source's redistribution terms before publishing copied transcriptions. See `LICENSE_NOTES.md`.
